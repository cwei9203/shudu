# 数独技巧训练小程序计划

## 已确认的产品方向

- 使用微信原生小程序开发。
- 目标用户是能够完成简单数独、遇到进阶技巧容易卡住的玩家。
- 首版优先完成技巧训练，自由玩保持基本可用。
- 学习目标是在明确指定技巧的局面中，独立识别结构并正确删除候选数。
- 首版包含显性数对、区块排除、X-Wing、XY-Wing、XYZ-Wing 五课。候选数和同行、同列、同宫关系作为前置短讲解。

## 已确认的练习规则

- 自动提供经过校验的当前候选数，保留中间局面已经完成的有效删数。
- 用户选择关键格及待删除的候选数。
- 结构符合指定技巧、提交至少一个由该结构推出的有效删数即可通过，不要求找全所有删数；提交内容不能包含错误删数。
- 接受指定技巧下的其他有效结构，不仅比对预设答案。
- 首先反馈错误类型；用户主动请求后再逐步揭示提示和答案。
- 揭示关键格或推导答案后记为辅助完成；原题重做不计入课程通过，需要换未揭示答案的题独立完成。仅说明错误类型的反馈不取消独立资格。
- 不扣分，不限制提示次数。
- 推荐学习顺序，但不锁定课程；高级技巧提供前置知识入口。

## 已确认的教学内容与验收

- 每课包含一个分步示例、一道引导题、三道独立题，共二十五个教学与练习局面。
- 独立题采用不同推理局面，不仅通过置换数字或旋转棋盘制造差异。
- 每课独立通过两道不同题即为课程通过。
- 未揭示答案的剩余题量不足以完成验证时，课程记为待独立验证，仍允许继续练习。
- 讲解采用用户点击下一步的分步高亮，配合简短推理文字；首版不制作自动播放动画。

## 题目与后续范围

- 首版使用精选固定题库，逐题校验局面、候选数、目标结构和解释。
- 自动生成训练题列为后续方向，当前不实现；可考虑用于课程通过后的持续训练。
- 旋转棋盘或置换数字属于题目变体，不等同于新的推理结构。

## 已确认的交付边界

- 自由玩提供精选题目、基础输入、笔记、撤销、计时、存档和完成判断；首版不提供任意局面的自动下一步技巧推荐。
- 无需登录，仅在当前设备本地保存课程状态、题目提示揭示记录、独立通过记录和未完成对局；清理小程序数据或换设备后不保证保留。
- 第一阶段交付以微信开发者工具可运行、手机预览验收通过为目标，不包含正式公开发布。

## 实施顺序与验收

1. 完成显性数对的完整教学切片：棋盘、分步示例、引导练习、独立练习和反馈。验收用户能理解讲解并独立提交结构与删数。
2. 实现五种技巧的结构校验与推导验证。检查结构、提交的删数以及二者的推理关系；接受符合指定技巧的其他结构，拒绝碰巧正确但不能由所选结构推出的删数。每种技巧保留可运行的正例和反例检查。
3. 补齐二十五个教学与练习局面。逐题检查底层题目唯一解、候选数状态、目标技巧、分步解释；裁剪展示区域时仍保留完整棋盘用于校验。每课三道独立题采用不同推理局面。
4. 接入课程进度与基础自由玩。本地保存提示揭示记录和通过状态，验证重进、重做及题目不足时不会误判课程通过。
5. 完成真机验收：检查小屏点击、候选数可读性、选中态与错误态、前后台计时、存档恢复，以及非预设有效结构的识别。

## 实现约束

- 使用原生 WXML、WXSS 和 JavaScript；优先复用棋盘与候选数显示逻辑，不引入不必要的框架。
- 区分唯一解验证和技巧判题：前者验证题目，后者验证用户使用指定技巧的推理。
- 训练候选数可能包含前序推导结果；不能在恢复或展示时重新计算基础候选数并覆盖这些结果。
- 错误反馈应区分结构无效、删数无效和删数不能由所选结构推出；用户主动请求后才揭示关键格或推导答案。
- 关键状态不可只靠颜色表达；提供文字或形状标记，并在窄屏真机上验证可操作性。

## 已知限制

- 每课仅三道独立题，连续查看答案可能使课程进入待独立验证；首版接受此限制，不通过重置提示记录制造独立通过。
- 课程通过表示达到本产品的练习标准，不代表用户已能在任意完整数独中识别该技巧。
- 自动生成训练题、云同步、任意局面技巧提示和公开发布不在第一阶段范围。
